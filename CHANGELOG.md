# Changelog

## 0.1.0

Initial preview release.

- Cadence branding, executable names, release archives, and application icon.
- Rotation of arbitrary performer selections and independent motion-route drawing.
- Follow-the-leader movement with forward, drawn-route, and optional guide modes.

- Field editor with performer selection, instrument labels, and reference coordinates.
- Formation guides, transforms, persistent sketch constraints, and compass proposals.
- Set and subset editing with holds, staggered timing, gates, floats, and follow-the-leader moves.
- Music playback with BPM and track offset controls.
- Versioned `.mdrill` documents, configurable shortcuts, and unsaved-change prompts.
- PNG chart export and PDF drill packets per performer.
- Release archives for Windows, Linux, and macOS on Intel and Apple Silicon.

### Limitations

- Collision avoidance applies to compass proposals; other generated maneuvers require review.
- Constant BPM only; music files remain external to project documents.
- Field dimensions and hash locations use a fixed college football template.
- Release binaries do not include code signing or macOS notarization.
